# 50+ 재취업 길잡이 (jobmatch50)

**배포 주소: http://3.105.22.205** (AWS EC2 시드니, 탄력적 IP로 고정, Docker Compose)

50대 이상 중장년 구직자를 위한 재취업 정보 통합 서비스. **배우고, 취득하고, 다시 일하기.**
거주 지역(시·도)과 관심 분야(조리·제과제빵, 운전·중장비, 전기·설비, 요양·돌봄, 경비, 사무·부동산 등 10개)를 고르면
네 가지를 한 화면에 모아 보여준다.

| 탭 | 내용 | 데이터 |
|---|---|---|
| 시험·자격증 | 우리 지역에서 많이 응시한 자격증 순위 → 누르면 다음 시험 D-day·응시료·지역 상설 시험장·국비 과정·**시·도별 채용공고 수** | 한국산업인력공단 Q-Net OPEN-API, 한국노인인력개발원 API |
| 국비 교육 | 3개월 안에 시작하는 국민내일배움카드 과정 | 고용24 훈련과정 API |
| 취업 | **지금 접수 중인 중장년 채용공고**(50세 이상 우대 표시, 고용24 원문 링크) + 고용센터 채용행사·현장면접 + 60세 이상용 노인일자리 기관 + 고용24·사람인·잡코리아 검색 바로가기 | 한국노인인력개발원 API, 고용24 채용행사 API |
| 알바 | 알바몬·당근알바 같은 조건 검색 바로가기, 알바 주의사항 | (공개 API 없음 → 링크만) |

무료, 회원가입 없음, **개인정보를 수집·저장하지 않는다** (로그인·DB 없음).

- 프런트: React 18 + Vite
- 백엔드: FastAPI (외부 API 호출 + 정제 + 메모리 캐시)
- 배포: AWS EC2 (Nginx가 React 정적 파일 서빙, `/api`는 Uvicorn으로 프록시)

## 1. API와 키

| API | 키 | 비고 |
|---|---|---|
| Q-Net 종목 목록 `InquiryListNationalQualifcationSVC` | 불필요 | 국가자격 613개, 종목코드·분야 |
| Q-Net 종목별 일정 `InquiryTestInformationNTQSVC/getJMList` | 불필요 | 상시 시험·국가전문자격 포함 |
| Q-Net 응시료 `InquiryTestInformationNTQSVC/getFeeList` | 불필요 | |
| Q-Net 시험장소 `InquiryExamAreaSVC` | 불필요 | 지사 코드별 |
| Q-Net 거주지별 접수 현황 `InquiryExameeAbdSVC` | 불필요 | 지역·종목·접수자 수. **연령대 항목은 없음** |
| 고용24 훈련과정 (310L01) | `WORK24_TRAINING_KEY` | |
| 고용24 채용행사 (210L11 목록, 210D11 상세) | `WORK24_JOB_KEY` | 개인회원 키로 됨 |
| 한국노인인력개발원 노인 구인정보 `SenuriService` | `DATA_GO_KR_KEY` | 공공데이터포털 활용신청(자동승인). 접수 중 공고 전국 약 260건 |
| 한국노인인력개발원 자립형일자리 수행기관 `JobBsnInfoService` | `DATA_GO_KR_KEY` | 활용신청 따로. 전화번호는 가려져 옴 |

- "키 불필요"는 2026-11-13 실측 결과다. `DATA_GO_KR_KEY`가 있으면 Q-Net 호출에도 함께 보낸다.
- `DATA_GO_KR_KEY`가 없으면 취업 탭의 중장년 채용공고·노인일자리 기관만 빠지고 나머지는 그대로 동작한다.
- 고용24 **일반 채용정보(210L01)는 기업회원 전용**이라 개인 키로는 `개인회원은 사용할 수 없는 OPEN-API입니다.` 오류가 난다.
  그래서 일반 공고와 알바는 공고를 복사해 오지 않고, 각 사이트의 같은 조건 검색 화면으로 연결한다
  (민간 사이트 무단 수집은 데이터베이스권 침해 판례가 있어 하지 않는다).

### 우리 API
| 주소 | 내용 |
|---|---|
| `GET /api/meta` | 시·도, 관심 분야 목록 |
| `GET /api/highlights` | 첫 화면 카드용 전국 숫자(중장년 대상 국비 과정, 많이 열리는 과정, 중장년 공고, 채용행사, 50·60대 1위). 30분 캐시 |
| `GET /api/hub?sido=&preset=` | 시·도+분야 결과(자격증 순위·50·60대 순위·국비 교육·채용공고·채용행사·노인일자리 기관·바로가기) |
| `GET /api/cert/{종목코드}?sido=` | 자격증 하나의 다음 일정, 응시료, 지역 상설 시험장, 국비 과정, 시·도별 채용공고 수(`job_counts`) |
| `GET /api/status` | 출처별 마지막 갱신 시각 |

### 50대·60대 인기 자격증
공개 API와 Q-Net 「국가기술자격 통계연보」에는 종목별·나이별 인원 표가 없다(등급별 합계만 있음).
그래서 한국산업인력공단 「2026 국가기술자격 수험자 기초현황」(2026.9.30 발표, 2025년 필기 응시자 1,856,264명) 순위를
`backend/app/data/age_top_2026.json`에 적어 쓴다. 공단이 순위만 공개해 인원은 표시하지 않는다. 매년 새 발표가 나오면 새 파일을 만든다.

### 지역 코드 주의
- 고용24 훈련 API의 전북 코드는 `52`다(`45`는 0건).
- 2026년 자료에서 광주 주소가 '전남광주통합특별시'로 오기도 해서, 시험장·노인일자리 기관은 광주와 전남을 같은 권역으로 본다.

## 2. 로컬 실행

```bash
# backend
cd backend
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # 고용24 키 입력
uvicorn app.main:app --reload --port 8000
pytest                             # 정제 로직 테스트 (키 없이 동작)

# frontend
cd ../frontend
npm install
npm run dev                        # http://localhost:5173  (/api → 8000 프록시)
```
8000번 포트를 다른 프로그램이 쓰고 있으면 백엔드를 `--port 8010`으로 띄우고
`API_URL=http://localhost:8010 npm run dev`로 프런트를 실행한다.

블로그 글에서는 지역·분야·탭을 미리 고른 링크로 바로 결과를 보여줄 수 있다:
`https://도메인/?sido=대구&preset=조리·제과제빵&tab=exams` (`tab`: exams / trainings / jobs / alba)

### 데이터 갱신 시각 확인
화면 맨 아래 '데이터 갱신 현황'에서 출처별 마지막 갱신 시각(몇 분 전, 날짜·시각)과 갱신 주기를 볼 수 있다.
같은 내용을 `GET /api/status`로도 받는다. 각 클라이언트가 원본 API에서 실제로 받아 올 때 `app/freshness.py`에 시각을 남기며,
서버를 다시 켜면 비워진다(서버 시작 때 종목 목록·중장년 공고·노인일자리 기관은 미리 받아 둔다).

### 다른 사이트 바로가기 아이콘
`frontend/public/favicons/`에 각 사이트 파비콘을 한 번 받아 저장해 쓴다(방문자 브라우저가 외부 아이콘 서비스에 요청하지 않도록).
당근알바는 검색어에 지역을 넣어도 브라우저에 설정된 '내 동네'로 열려서, 검색어만 넘기고 동네를 바꾸라고 안내한다.

### 신청·접수 바로 가기
첫 화면 결과 아래(위 메뉴 '신청·접수')에 국비 교육 신청·자격증 시험 접수 화면으로 바로 가는 링크를 둔다. 주소는 `App.jsx`의 `APPLY`에 있고,
기관이 주소를 바꾸면 거기만 고친다(2026-11-14 직접 열어 확인).

| 링크 | 주소 | 비고 |
|---|---|---|
| 내일배움카드 발급 신청 | `work24.go.kr/hr/h/a/1100/selectIssuGudn.do` | 발급 안내 화면 안에 '발급신청' 버튼 |
| 훈련 과정 찾기·신청 | `work24.go.kr/hr/a/a/1100/trnnCrsInf.do` | 고용24 '훈련 찾기·신청' 메뉴 |
| 원서접수 신청 | `q-net.or.kr/rcv202.do?id=rcv20210` | 로그인 화면으로 먼저 열리고 로그인하면 접수 화면 |
| 이번 달 시험 일정 | `q-net.or.kr/crf021.do?id=crf02103&CST_ID=CRF_Stns_06` | 월간 시험일정 |
| 요양보호사 시험 | `kuksiwon.or.kr/index.do` | 메뉴를 스크립트로 그려 접수 화면 주소를 확인하지 못해 첫 화면 |

### 접수 통계 갱신
지역별 자격증 순위는 `backend/app/data/qnet_stats_YYYY.json`을 읽는다. 1년치 기능사 데이터가 약 6만 행이라 미리 만들어 둔다.
```bash
cd backend && python -m app.build_stats --year 2025     # 약 1분, 60회 호출
```
새 연도 파일이 생기면 가장 최근 연도를 자동으로 쓴다.

### 자격증 → 시·도별 채용공고 수 (`jobcount.py`)
자격증 상세를 열면 그 자격증 관련 공고가 시·도마다 몇 건인지 막대로 보여준다(내 지역 순위·지금 접수 중 건수 포함).

- **지금 출처는 노인 구인정보**(50세 이상 대상 공고)다. 정확한 전체 공고 수를 주는 고용24 채용정보 API(210L01)는
  기업회원 전용이라 개인 키로는 `개인회원은 사용할 수 없는 OPEN-API입니다` 오류가 난다(2026-11-14 확인).
- 기간은 최근 2년. 실측(2026-11-14, 전국, 아래 정제 후): 경비 454건, 조리 96건, 사회복지사 63건, 전기 38건, 지게차 16건.
  공고가 10건 미만이면 화면에 '공고가 적어요' 안내와 고용24 검색 링크를 띄운다.

| 원본 | 실제로 오는 값 | 정제 |
|---|---|---|
| 검색어 | 자격증 이름 그대로는 거의 0건('한식조리' 2년 0건) | 등급·급수·'운전'·괄호를 뗀 이름을 `KEYWORDS` 표로 공고 제목에 쓰이는 말로 바꿈(한식조리기능사 → 조리, 굴착기 → 굴착기·굴삭기·포크레인). 표에 없으면 뗀 이름 그대로 |
| 뗀 이름에 맞추는 이유 | '로더**운전기**능사', '산업안전지도사(**전기**안전)' | 원래 이름에 맞추면 전기 공고로 잘못 셈 |
| 검색 결과 | 제목 속 글자를 그대로 찾아서 '전기' → 택시 '운**전기**사'·'건설안**전기**사'·'전기렌지 조립', '목공' → '토**목공**사', '선반' → '영**선반**', '떡' → '떡갈비' | 받아 온 제목을 `TITLE_RULES`로 한 번 더 거름(전기 130건 → 38건) |
| 재등록 | 한 회사가 같은 공고를 jobId만 바꿔 여러 번 올림(굴삭기 4건이 모두 한 회사) | 회사 이름 + 근무지 코드 + 글자만 남긴 제목이 같으면 1건(다른 지역에 낸 같은 제목 공고는 다른 일자리), 가장 최근 것의 '접수 중' 여부를 씀 |
| 목록 | 최신순, 한 번에 최대 1,000건. 경비는 1,000건이 약 1년 5개월 | 2년 전까지 내려갈 때까지 다음 쪽을 받음(최대 5쪽, 넘으면 화면에 '최근 일부만 셌어요'). 1시간 캐시 |
| 지역 | `workPlc` 앞 두 자리 = 회사 소재지 시·도 | 광주·전남은 한 권역('광주·전남') |
- 고용행정통계(EIS) 구인 API는 키 없이 되지만 직종이 대분류 10개뿐이고 시·군·구×성별×연령이 필수라 쓰지 않았다.

**고용24 채용정보 키를 받으면**: `jobcount.job_counts()`의 데이터 부분만 210L01 호출(자격면허·근무지역 필터, 시·도마다 총건수)로 바꾼다.
화면이 쓰는 반환 모양(`summarize()` 결과)과 `SOURCE` 설명만 맞추면 프런트는 고치지 않아도 된다.

### 국비 교육 (`cleaning/training.py`)
수강비(`courseMan`)만 보여주고 자부담은 "카드 종류·소득에 따라 다름"으로 안내한다(`realMan`은 자부담이 아님 — 실측 100건 중 92건이 수강비와 같음).
만족도는 100점 만점으로 통일하고 0은 '평가 없음'. 회차만 다른 같은 과정은 가장 빨리 시작하는 회차 1건만 남긴다.

### 정제 로직을 고칠 때
`backend/tests/fixtures/`에 실제 응답에서 본 이상한 케이스를 추가하고 `pytest`로 확인한다.
픽스처에 개인정보(담당자 이름·이메일 등)가 들어가지 않게 지운 뒤 커밋한다.

## 4. 도커로 실행·배포 (권장)

```
docker-compose.yml        api(FastAPI, 8000) + web(Nginx가 React 빌드 서빙, /api 는 api로 전달, 80번)
backend/Dockerfile        python:3.12-slim + uvicorn
frontend/Dockerfile       node:20 빌드 → nginx:1.27-alpine
frontend/nginx.conf       정적 파일·/api 프록시·gzip·캐시
deploy/docker-deploy.sh   EC2에서 도커 설치·스왑·빌드·실행을 한 번에
```

```bash
cp backend/.env.example backend/.env   # 인증키 입력 (깃허브에는 올리지 않음)
docker compose up -d --build           # http://localhost
```

EC2(Ubuntu):
```bash
git clone https://github.com/a01043547533-lang/1113.git jobmatch50 && cd jobmatch50
nano backend/.env                      # 인증키
bash deploy/docker-deploy.sh           # 도커 설치 → 빌드 → 실행 → /health 확인
```
보안 그룹 인바운드에 80(HTTP)을 열어야 한다. 코드를 고친 뒤에는 서버에서 `bash deploy/docker-deploy.sh`를 다시 실행한다.

## 5. AWS EC2 배포 (도커 없이)

1. EC2 인스턴스 생성: Ubuntu 22.04/24.04, t2.micro(또는 t3.micro), 보안 그룹 인바운드 **22(내 IP), 80, 443** 허용
2. 접속 후:
   ```bash
   git clone https://github.com/a01043547533-lang/1113.git jobmatch50
   cd jobmatch50
   bash deploy/setup.sh          # 처음엔 .env가 없어서 멈춘다
   nano backend/.env             # 고용24 키 입력
   bash deploy/setup.sh          # 다시 실행 → 패키지 설치, 빌드, nginx·systemd 등록
   ```
3. 브라우저에서 `http://<EC2 퍼블릭 IP>` 접속
4. 코드를 고친 뒤에는 서버에서 `bash deploy/update.sh` (git pull → 테스트 → 빌드 → 재시작)
5. 도메인을 연결했으면 `deploy/nginx.conf`의 `server_name`을 바꾸고
   `sudo apt install certbot python3-certbot-nginx && sudo certbot --nginx`로 HTTPS 적용

로그 보기: `sudo journalctl -u jobmatch50 -f`

`.env`(인증키)는 `.gitignore`에 들어 있어 GitHub에 올라가지 않는다. 서버에서 직접 만든다.
